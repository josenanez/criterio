# Criterio · version 0.12.1 · 28 October 2026

From this version on, **each family carries its own version number** (decision 0017): the PMO, the CFO, the CLO, the EA and Rostrum each go up only when they change. A release of one family no longer asks the users of the others to accept the terms again. Open source under Apache 2.0.

## What it brings

| | |
|---|---|
| **One version per family** | Every plugin of a family carries that family's number. The marketplace carries the catalogue number, which goes up with each entry of the version register. The register stays a single chain, and each new entry records the version of every family and of every plugin, and which families were released in it |
| **Terms 1.3** | They speak of every family, not only the PMO: the rounds of each family's agents on synthetic material from several industries and countries, with control entities; the evidence of each family; and that each family has its own version |
| **Ofelia** | The fix for EA-8, verified the same day as 0.12.0: what is still unknown about a decision no longer repeats what the documents already say |

## If you already have it installed

With auto-update on, the new version arrives by itself. Since the terms changed, each agent asks you to accept them again, and leaves its receipt in `.criterio/terminos/`.
